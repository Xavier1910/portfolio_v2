# Xavier Akash M — Developer Portfolio

> **Live at:** [your-vercel-url.vercel.app](https://your-vercel-url.vercel.app)

A terminal-inspired, VSCode-themed developer portfolio built with **React + Vite + Tailwind CSS** — featuring a boot loader, interactive terminal, code rain, AI developer chat, and animated section reveals.

---

## ⚡ Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| Deployment | Vercel |

---

## 🗂 Project Structure

```
src/
├── assets/              # Static images
├── components/
│   ├── BootLoader.jsx         # Terminal boot animation
│   ├── CodeRain.jsx           # Matrix-style background
│   ├── ContactConsole.jsx     # Contact section
│   ├── CustomCursor.jsx       # Custom cursor effect
│   ├── DeveloperChat.jsx      # AI-style chat widget
│   ├── DeveloperSidebar.jsx   # VSCode-style sidebar
│   ├── EducationLog.jsx       # Education section
│   ├── ExperienceTimeline.jsx # Work experience
│   ├── Footer.jsx
│   ├── HeroTerminal.jsx       # Hero section terminal
│   ├── InteractiveTerminal.jsx
│   ├── MotionSection.jsx      # Scroll reveal wrapper
│   ├── ProfileBlob.jsx        # Animated profile display
│   ├── RepositoryCards.jsx    # Projects section
│   ├── SkillsMap.jsx          # Skills visualizer
│   ├── StatusBar.jsx          # VSCode-style status bar
│   ├── SuperTerminal.jsx      # Interactive terminal overlay
│   └── TopBar.jsx             # VSCode-style top bar
├── data/
│   └── portfolioData.js       # ✏️ All your personal data lives here
├── hooks/
│   └── useScrollReveal.js
├── App.jsx
├── App.css
├── index.css
└── main.jsx
```

---

## ✏️ Customization

All personal content — name, roles, experience, projects, skills, education, certifications, and chat responses — is centralized in **one file**:

```
src/data/portfolioData.js
```

Edit that file to update your portfolio without touching any component.

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
